    Semantic

    Semantic Element¶

    Semantic element adalah element HTML yang khusus diperuntukkan sesuai fungsinya dalam hal layouting

    Berikut adalah element-element yang termasuk element semantic

    • <header>
    • <main>
    • <footer>
    • <nav>
    • <aside>
    • <section>
    • <article>

    Tree Structure¶

    Berikut adalah struktur dari semantic element apabila digambarkan melalui tree structure

    Contoh¶

    Berikut adalah cara yang benar dalam menggunakan semantic element

    <body>
  <header>
    <nav aria-label="Main navigation">
      <ul>
        <li><a href="/">Home</a></li>
        <li><a href="/articles">Artikel</a></li>
        <li><a href="/about">Tentang</a></li>
      </ul>
    </nav>
  </header>

  <main>
    <aside>
      <nav aria-label="Sidebar navigation">
        <section>
          <h2>Kategori</h2>
          <ul>
            <li><a href="/category/html">HTML</a></li>
            <li><a href="/category/css">CSS</a></li>
            <li><a href="/category/javascript">JavaScript</a></li>
          </ul>
        </section>

        <section>
          <h2>Referensi</h2>
          <ul>
            <li><a href="/docs">Dokumentasi</a></li>
            <li><a href="/tutorials">Tutorial</a></li>
            <li><a href="/resources">Resources</a></li>
          </ul>
        </section>
      </nav>
    </aside>

    <article>
      <h1>Belajar Semantic HTML</h1>

      <p>
        Semantic HTML membantu browser, search engine, dan screen reader
        memahami struktur halaman dengan lebih baik.
      </p>

      <h2>Mengapa Semantic HTML Penting?</h2>

      <p>
        Dengan elemen seperti header, nav, main, article, section, aside, dan
        footer, struktur dokumen menjadi lebih jelas dan mudah dipelihara.
      </p>
    </article>
  </main>

  <footer>
    <nav aria-label="Footer navigation">
      <section>
        <h2>Website</h2>
        <ul>
          <li><a href="/about">Tentang Kami</a></li>
          <li><a href="/contact">Kontak</a></li>
          <li><a href="/privacy">Kebijakan Privasi</a></li>
        </ul>
      </section>

      <section>
        <h2>Media Sosial</h2>
        <ul>
          <li><a href="#">GitHub</a></li>
          <li><a href="#">LinkedIn</a></li>
          <li><a href="#">X / Twitter</a></li>
        </ul>
      </section>
    </nav>
  </footer>
</body>
